# Sword UI Asset Selection

This record covers only the assets imported for the sword tile and fantasy UI pass.

## Visual Direction

Selected style: compact fantasy armory. The board reads as an equipment tray where matching blades are forged into stronger swords. The Free Inventory UI subset was chosen because its wood/leather slot language supports puzzle readability without adding characters, combat, or scenery.

## Sword Progression

- `2`: `Swordtember_27.png` from `Swordtember 2024.zip`; plain steel silhouette for the starting rank.
- `4`: `Swordtember_01.png`; simple flame accent, still readable at tile size.
- `8`: `Swordtember_04.png`; stronger forged blade with a broad warm shape.
- `16`: `Swordtember_08.png`; gold blade, clear escalation.
- `32`: `Swordtember_09.png`; blue crystal blade with strong contrast.
- `64`: `Swordtember_14.png`; rune-green sword with higher visual complexity.
- `128`: `Swordtember_17.png`; bright sky blade for first milestone rank.
- `256`: `Swordtember_21.png`; red gem sword with compact silhouette.
- `512`: `Swordtember_23.png`; arcane multicolor sword for high-rank emphasis.
- `1024`: `Swordtember_26.png`; ornate icy relic blade.
- `2048`: `Swordtember_28.png`; crystalline mythic blade.
- `4096+`: `Swordtember_30.png`; red relic fallback for all unusually high ranks.

## UI Assets

- `Inventory_background.png` from `User Interface.zip`; board/drop/preview panel overlay.
- `Inventory_Slot.png`; occupied, empty, and preview cell slot overlay.
- `Inventory_select.png`; active/valid/invalid placement overlay.
- `Inventory_Bar.png`; selected for the forge/chain meter source family.

## VFX

- `Attack_Up.png`; game-over feedback reference.
